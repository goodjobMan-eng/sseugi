# 쓰기공책 — 원고지 받아쓰기

초등 1~2학년이 태블릿과 펜으로 **진짜 공책·원고지에 쓰듯** 받아쓰기를 하는 무료 웹앱입니다.
가입 없음, 기록은 기기 안에만 저장, 한 번 열면 인터넷 없이도 씁니다.

▶ **바로 열기:** https://goodjobman-eng.github.io/sseugi/

- 공책 세 권: 따라 쓰기(원고지) · 받아쓰기(단계는 공책을 펼쳐서 고름) · 자유 쓰기
- 7~36단계 받아쓰기 문장 344개, 성우 목소리 두 명(레다·카론)
- 연필 필압·기울기, 사각 소리, 지우개, 지우개 가루 털기, 연필깎이
- 손글씨 인식(한글 2,350자 인공지능, 기기 안에서 돌아감)과 채점, 틀린 까닭 알려 주기
- 선생님 시험지: 자물쇠를 눌러 암호를 넣으면 공책 칸에 문제가 흐리게 보임
- 시험 모드: 같은 시간대에는 모든 학생이 같은 문제·같은 순서
- 가벼운 모드(기본으로 켜짐): 보급형 태블릿에서도 빠르게

자세한 사용법은 [안내.md](안내.md)를 보세요.

## 태블릿에 설치하기
크롬에서 주소를 연 뒤 메뉴 → **홈 화면에 추가(앱 설치)**. 첫 화면 오른쪽 위 설정에서 「미리 받기」를 한 번 누르면 받아쓰기 목소리도 인터넷 없이 나옵니다.
